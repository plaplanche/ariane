# Product brief: Security hardening: the reviewer's instruction files, untruncated changed-file list, no surviving agent processes (C10)

## Context

Hardening from an internal security review (17 October 2026, main at be82d05). The reviewer must judge the change from the diff and the tree only (C10, ADR 0031). Three things can weaken that today: instruction files the reviewer's runtime loads from outside the review tree, a very large diff that is truncated, and agent processes that keep running after their session ends. Spec: C10, C26; ADR 0031.

## Current state

- `src/ariane/review_session.py:70` starts the reviewer in an empty temporary working directory; `src/ariane/claude_code.py:49-54` starts Claude Code in restricted mode, which ignores user settings and hooks; ADR 0031 records that ancestor `CLAUDE.md` files are still loaded. The guard snapshot (`src/ariane/git.py:187-227`) does not cover instruction files outside the repository (ancestors of the reviewer's directories, `~/.claude/CLAUDE.md` or `$CLAUDE_CONFIG_DIR`, opencode's global `AGENTS.md` and config).
- `src/ariane/review.py:229-231` cuts the diff at 200,000 characters and only says "(diff truncated; read the files in the working tree)".
- `src/ariane/process.py:139` starts sessions in their own process group and `process.py:232-243` (`kill_tree`) kills that group only; a process that starts a new session survives it.

## Decided spec

- **Instruction files snapshot:** before each reviewer session, record the digests of the instruction files the configured reviewer runtime can load: `CLAUDE.md` and `CLAUDE.local.md` in every ancestor of the reviewer's working directory and of the reviewer tree, the user-level Claude file (`$CLAUDE_CONFIG_DIR/CLAUDE.md` or `~/.claude/CLAUDE.md`), and for opencode its global `AGENTS.md` and config. Take the same snapshot before the implementer's session; a difference after the implementer's session stops the ticket as a guard violation.
- **No silent truncation:** the review prompt always holds the untruncated `git diff --name-status` of the whole range (inside the untrusted-data envelope); when the diff is cut, the prompt names the files whose hunks are missing, and the journal and the pull request body say so.
- **Surviving processes (Linux):** Ariane sets `PR_SET_CHILD_SUBREAPER`; after each agent session, check and setup command, any remaining descendant is killed, counted in `metrics.json`, and the ticket stops as a guard violation. On macOS and Windows this is recorded as a residual in ADR 0031 (Job objects and a scan are later work).
- ADR 0031 amendment.

## Release note

Security: the reviewer's instruction files are guarded, the review always sees the full list of changed files, and agent processes cannot outlive their session on Linux.
