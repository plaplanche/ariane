# Product brief: Let a check declare the tests it cannot run locally, record them, and tell the reviewer nothing ran them (C9, C10)

## Context

Some tests only run in CI. In the benchmark on a reference project, the browser end-to-end tests are skipped on the machine that runs Ariane because the browser cannot be downloaded there; only CI runs them. Two independent implementers wrote the same wrong browser test (it waited for a page load at a redirect URI that nothing serves), the replay passed because the test was skipped, neither reviewer noticed, and CI went red after delivery. Ariane cannot run these tests, but it can know that it did not, say so in the records, and make the reviewer read them as code that no check has exercised. Spec: C9 ("never believes an agent", the report per check), C10 (the reviewer reads with the replay's results), C26.

## Current state

## Decided spec

- New optional key `checks[].not_run_locally`: a list of path globs (same glob rules as `documentation.map`, `src/ariane/config.py:121-137`), naming the files whose tests the check skips when Ariane replays it (they run only in CI). An empty list or a non-string entry is refused, naming the key.
- **Records.** For a check with `not_run_locally`, `checks.md` adds under its section: "Not run by this replay (CI only): `<globs>`", and lists the files of the ticket's diff that match (or "no changed file matches"). The summary table is unchanged.
- **Reviewer.** When changed files match, the reviewer prompt adds a block: "These changed files hold tests that no replay ran (only CI runs them). Read each one as untested code: check every URL, selector, wait and fixture it uses against what the code under review actually serves or produces, and report a blocking finding for a test that cannot pass." followed by the file list as untrusted data (paths come from the agent's diff).
- **Implementer.** The implementer's list of checks marks such a check: "`<name>`: `<command>` (does not run `<globs>` locally: only CI does; write those tests with extra care)".
- No detection from the check's output (projects word skips differently): the declaration is the source.
- A new ADR (next free number) records the key and why it is declared, not detected.
