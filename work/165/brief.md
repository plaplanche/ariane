# Product brief: Security hardening: the tracker token lives only in the tracker and the push (C11, C21)

- Source: issue #165 (https://github.com/plaplanche/ariane/issues/165)

## Context

Hardening from an internal security review (17 October 2026, main at be82d05). Ariane already withholds credential variables from the environments it gives agents, checks and setup commands (C21, ADR 0017), but the tracker token stays in Ariane's own process environment for the whole run and is passed to every git command Ariane runs, not only to the push. This ticket narrows where the token lives. Spec: C11, C21; ADR 0017.

## Current state

- `README.md:28` and `:38` tell the owner to export the token as `GH_TOKEN`; `src/ariane/cli.py:172`, `:189`, `:223` read it from `os.environ` and leave it there.
- `src/ariane/flow.py:480` and `src/ariane/delivery.py:46-47` keep the token and the full environment for the run.
- `src/ariane/git.py:47-51` runs Ariane's own git commands with the full environment (`env=None`); `git.py:385` pushes with `os.environ`.
- On Linux nothing prevents a same-user process from reading Ariane's environment block.

## Decided spec

- **Linux:** at CLI start, `prctl(PR_SET_DUMPABLE, 0)` through `ctypes` (a no-op elsewhere; failure to call it is journaled as a warning, never fatal).
- **One place for the token:** once `token_env` has been read, its value is removed from `os.environ` and kept only in the tracker and the push.
- **Token-free git:** `git.git()` and `git.out()` use, by default, the environment without `token_env` and without any variable the credential filter withholds; only `git.push` receives the authentication header, as today.
- **README:** recommend a fine-grained token limited to the one repository (contents, pull requests and commit statuses: write; issues: read; no workflows, no administration), and state the residual: on macOS, on Windows and when running as root, only the sandbox of the security slice closes it.
- ADR 0017 amendment: where the token lives during a run, and the residuals.

## Release note

Security: the tracker token is removed from Ariane's environment once read, never given to non-push git commands, and Ariane's process is not dumpable on Linux.
